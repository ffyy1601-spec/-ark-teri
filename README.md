# Ayşem Gıda (Elbistan / Kahramanmaraş) — Doğal Köy Ürünleri & Şarküteri Web Sitesi

Elbistan ve Kahramanmaraş yöresine ait katkısız, doğal, köy usulü ve organik şarküteri ürünlerini tanıtan, mobil öncelikli (Mobile-First) ve doğrudan **WhatsApp Sipariş Hattı** entegrasyonlu web arayüzü.

## Öne Çıkan Özellikler
- **Mobil Öncelikli (Mobile-First) UI/UX:** Başparmak ergonomisine uygun yatay kaydırmalı kategori filtreleri ve mobil alt yapışık (sticky bottom) sipariş barı.
- **Doğrudan WhatsApp Sipariş Mimarisi:**
  - Her ürün kartında tek tıkla ürün adını mesaj şablonuna ekleyen *"WhatsApp ile Sipariş Ver"* butonu.
  - Birden fazla ürünü miktar/kilo seçerek tek mesajda toplu olarak WhatsApp'a ileten **Sipariş Listesi Çekmecesi (Order Drawer)**.
- **Yerel SEO (Elbistan / Kahramanmaraş):**
  - Semantik HTML5 mimarisi (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
  - `LocalBusiness` ve `GroceryStore` Schema.org (`JSON-LD`) yapısal veri bloğu.
- **Hızlı Kurulum:** Sıfır bağımlılık, tek dosya (`index.html`) üzerinden doğrudan GitHub Pages, Vercel veya Netlify üzerinde yayınlanmaya hazırdır.
